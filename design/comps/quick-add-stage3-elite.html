Stage 3 — Design Notes
A · Editorial ReceiptCarries the recessed glass-panel pattern from stages 1/2: a context strip (template/category + account, separated by a hairline), then a gradient-hairline amount panel with Fraunces hero, JetBrains Mono expression, and a dotted-rule footer line. Multi-currency picker is a champagne mono pill inside the panel; single-currency falls back to a label-only suffix.
B · Vault DisplayStrips chrome: context collapses to a JetBrains Mono breadcrumb line; the amount panel becomes a ceremonial vault with a hairline-marquee label, larger 64px Fraunces hero, and a currency code pill anchored beside the figure. Better for one-shot entry; weaker if many accounts/templates need to be reconfirmed at glance.
NumpadGhosted dashed-border placeholder both variants — to be redesigned as a final pass with column key spacing, op-key champagne tint, and the existing expression/result wiring carried over from CalculatorNumpad.
FooterIdentical to stages 1/2: back chevron · 3-dot progress (third filled) · champagne CTA reading "SAVE" with a checkmark.
