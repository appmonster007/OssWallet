Current State — Dark Observations
Nav pill top bar: glass blur backdrop, champagne back arrow, Inter semi-bold label inside a frosted pill on the screen background tint.
Hero triple stack: JetBrains Mono "PREFERENCES" overline in accent / Fraunces 300 "Settings" display / JetBrains Mono "v1.1.0" in m2 — gap between overline and title is 4dp + 2dp spacer.
Section panels: 28dp corner radius, #161614 prominent surface, 0.5px champagne hairline border. Overline left-aligned inside panel, rule extends to right edge via weight(1f).
Item rows: 32dp circular icon (screenBackground fill + 0.5px outlineVariant border, 16dp icon inside), Inter Bold 12sp title + JetBrains Mono 9sp ALL-CAPS subtitle, champagne ChevronRight 24dp.
Dividers: Dotted repeating gradient, 1px height, inset 16dp from edges via aeonDottedUnderline modifier applied to a 1dp Box.
Current State — Known Issues
Icon duplication: Both "Transaction Templates" and "Smart Suggestions" use Icons.Rounded.AutoAwesome — identical icons for visually distinct features create scanability loss.
Version as plain text: "v1.1.0" sits as bare mono text with no visual container — easy to overlook. A pill badge would give it functional affordance (e.g. tap for changelog).
All icons same tint: Every icon uses contentSecondary regardless of section category. No colour-based scanability across 4 very different domains.
Footer visual weight: Footer text sits directly after last panel at 32dp spacing — same gap as between panels. It needs a separator or increased breathing room to signal "end of config".
Section header rule: 0.5px hairline extends full width to card edge but abruptly ends. A gradient fade-to-transparent would feel more editorial.

Implementation Proposals — Compose Code Notes
Hero
Version badge pill
Replace the bare Text("v1.1.0", style = metaLabel) with a small pill container using Surface(shape = CircleShape, color = AppColors.accent.copy(alpha=0.10f)). Add a 4dp dot using a 4x4 Box(CircleShape) tinted accent.copy(alpha=0.7f). This turns the version into a tappable affordance for a future "What's new" sheet.

The pill keeps the same JetBrains Mono 9sp text but the container anchors it visually and separates it from the hero title's vertical rhythm.
Section Icons
Section-scoped icon colour
Pass an optional iconTint: Color = AppColors.contentSecondary parameter to AeonSettingsItem and default it to contentSecondary to stay backward-compatible. In SettingsScreen pass section-specific tints:

Personalization: AppColors.accent (champagne)
Financial Setup: AppColors.incomeGreen
Automation: a cool-steel tint (Color(0xFF89B4D6))
Privacy: AppColors.expenseRed.copy(alpha=0.85f)

This is a single-field change to the section call sites — no architecture change required.
Section Header
Gradient rule + left accent bar
Two targeted changes to AeonSettingsSection:

1. Replace the flat background(AppColors.outlineVariant) on the hairline Box with a Brush.horizontalGradient(listOf(AppColors.outlineVariant, Color.Transparent)). One line change.

2. Add an optional accentColor: Color? = null parameter. When non-null, render a 2dp wide Box(Modifier.fillMaxHeight().width(2.dp).background(accentColor.copy(alpha=0.5f))) absolutely positioned at start=0 inside the outer Box.
Icon Dedup
Distinct icon for Templates vs Suggestions
Both "Transaction Templates" and "Smart Suggestions" currently use Icons.Rounded.AutoAwesome. Replace Templates with Icons.Rounded.TableRows or Icons.Rounded.ViewCompact (grid-like, structured) and keep AutoAwesome for Suggestions (sparkle = AI / smart). This is a one-character change per call site in SettingsScreen.kt.
Footer
Hairline separator before footer
The footer currently floats at the same spacing2xl (32dp) gap as inter-section spacing — nothing signals "content ends here". Add a HorizontalDivider(color = AppColors.outlineVariant, thickness = 0.5.dp) inside SettingsFooter before the tagline text, then increase vertical padding to spacingXl (24dp) above the tagline. Keeps the footer from blending into the settings list.
Motion
Staggered entrance animation cues
The screen currently has no entrance choreography. Recommend wrapping each AeonSettingsSection in an AnimatedVisibility(visible = sectionVisible, enter = fadeIn(tween(280)) + slideInVertically(tween(280, easing = EaseOutExpo), initialOffsetY = { it / 4 })). Use a LaunchedEffect with stagger: section 1 at 0ms, section 2 at 60ms, section 3 at 120ms, section 4 at 180ms. No VM change needed — pure composable state with remember { mutableStateOf(false) }.
