Design Decisions

  • 01 Fraunces 300 at 44px for the hero "Settings" — the page title acts as editorial display, not a functional nav label
  • 02 Section overlines use JetBrains Mono 8px / .36em tracking — same rhythm as card readouts in the dashboard
  • 03 Row icons are 36×36 hairline-bordered inset squares — monochrome thin-line SVGs, no fill, no color coding
  • 04 Row separators use dotted 1px hairline (matching ledger rows across all H comps), not solid dividers
  • 05 Active values (currency code, count, toggle state) render in champagne accent using JetBrains Mono — same as dashboard readouts
  • 06 Destructive section gets a separate panel with low-opacity red border gradient and red overline — never mixed into functional groups
